# C04/C05 扫描增强

**状态：** 开发版，默认关闭。2026-11-22 完成桌面 Worker、单元测试与 Chromium E2E；真机矩阵待补。

DocuLens 在原有「找边 → 透视矫正 → 光照均衡 → 二值化」流水线中增加两个可组合、默认关闭的增强开关：

- **周期噪声/摩尔纹**（C04）：在 1:1 图块上检测周期峰，对全分辨率灰度图做高斯陷波。
- **模糊复原**（C05）：估计运动/离焦 PSF，用全图 Wiener 或 FIR 近似复原。

处理顺序固定为：

```text
rectify → C04 → C05 → normalizeLighting → adaptiveThreshold → RGBA
```

关闭时只有布尔分支，不分配额外 Mat，不改变现有行为。输出分辨率始终与矫正后的扫描图一致；内存不足时跳过并提示，绝不静默降采样。

## 引擎

`engine/opencv_js.config.py` 的 `core` 白名单新增：

- `dft`（正/逆变换，`DFT_INVERSE` 即逆变换）
- `getOptimalDFTSize`

不新增 `mulSpectrums`：全图复数乘法在 JS 中就地完成，避免物化额外的全图复数谱。重建方式不变：

```sh
DOCULENS_BUILD_JOBS=6 bash engine/build.sh
```

`finalize.py` 会更新 `BUILD_INFO.json` 的 artifact sha 与 `configSha256`。本次重建 wasm 增加约 392 字节（3,019,344 → 3,019,736）。运行时有能力守卫：引擎无 `dft` 时两个开关禁用。

## C04：周期噪声/摩尔纹

1. **检测**：在矫正后的扫描图上取最多 5 个 1:1 的 1024²（或更小 2 的幂）图块，按梯度能量选择；每块乘 Hann 窗后做 `dft`。
2. **峰值**：对数幅度谱的 5×5 局部极大，频率范围 0.01–0.45 cycles/px，显著度 ≥2；校验共轭峰幅度差 ≤3dB；跨图块按 1/1024 频率投票，取置信度最高的 ≤8 对。
3. **背景校验**：文字行也会形成周期峰，但不会出现在空白区域。取图像中方差最低的 32×32 块，用最小二乘拟合每个候选正弦；只保留该块中振幅 ≥1.2 灰度级的分量。若最低方差块的标准差 >35（说明没有可靠空白区域），直接跳过。
4. **陷波**：≤12MP 时把全图反射补边到 `getOptimalDFTSize` 尺寸，前向 `dft`，对每个峰在 4σ 邻域乘高斯增益，逆变换写回；σ = clamp(0.002 × 最长边, 2, 24)。>12MP 时改用全分辨率正弦分量最小二乘减除，避免全图复数谱。
5. **回退守卫**：处理后检查强边缘（梯度 ≥60）是否保留 ≥85%；不足则恢复原图并跳过，防止误伤文字。

实测（512×640 合成图，条纹 0.08/0.03 cycles/px、振幅 22，种子 17/46/83）：ΔPSNR **+9.70 dB**，ΔSSIM **+0.383**。清晰文字图不产生候选峰，完全不改动像素。12MP（4000×3000）全图陷波在桌面 Chromium 上约 **1.04s**，完整扫描约 1.38s；分配全图复数谱会触发 WASM 堆增长，所有 `Mat.data`/`data32F` 视图都在分配后重新获取。

已知限制：只处理灰度亮度通道，纯色度摩尔纹不可见；宽带/局部相位变化的摩尔纹只能有限改善；没有可靠空白区域的紧裁图会保守跳过。

## C05：运动/失焦模糊复原

### PSF 估计

- 在 1:1 的 256–1024² 高梯度图块上做 `dft`，最多 2 块并做一致性惩罚。
- **运动**：对数幅度谱去径向基线后逆变换得到倒谱，在半径 3–31 px 搜索负峰，得到长度与角度；置信度由 z-score 映射。
- **离焦**：同时尝试三条路径，取置信度最高者：
  - 倒谱负环半径；
  - 径向频谱第一零点（`ρ0 ≈ 0.61/R`）；
  - 强边缘 10%–90% 上升宽度（对文字文档更稳）。
- 自动模式置信度 <0.55 时跳过；用户显式选择「运动/失焦」时阈值降为 0.2。超出范围（运动 3–31 px、离焦 1.5–12 px）一律跳过并回传诊断。

### 复原

- PSF 栅格 256（强模糊用 512），`H = conj(K)/(|K|²+0.02)`，增益上限 6，0.45 cycles/px 处平滑截止。
- **≤12MP**：反射补边后全图 `dft`，按归一化频率双线性采样 H 并原地复数乘，逆变换；结果与原图按 `strength=0.75` 混合。
- **>12MP 或内存预检失败**：由 H 逆变换截断 65×65/15×15 FIR，用 `filter2D` 全分辨率卷积（核已按相关语义翻转）。12.8MP、水平 9 px 运动模糊在桌面 Chromium 上约 2.35s。
- 全部失败只回传 `applied=false` 与原因，输出保持全分辨率原图。

实测（512×640 合成图）：水平 9 px 运动模糊估计为 9.0 px / 0°，全图 Wiener ΔPSNR **+1.45 dB**、ΔSSIM **+0.035**。带大块边缘的离焦样本可估计出 3–4 px 半径并复原；文字过密的离焦样本按设计跳过。

已知限制：

- 不实现课程实验中的全变分去卷积。12MP × 80–960 次迭代在单线程 WASM 上不可接受；C05 的增益因此明显小于课程 TV 结果。
- 未知 PSF 的估计依赖内容；低置信度会跳过，不强行出图。
- `>12MP` 的 FIR 降级使用 15×15 核，强模糊（运动长度 >15px 或离焦半径 >8px）只能近似复原，质量低于全图 Wiener。
- `filter2D` 是相关而非卷积，FIR 核已翻转；不要在后续修改中重复翻转。
- 只处理灰度，彩色输出/彩色摩尔纹不在本期范围。

## 交互

- 「周期噪声/摩尔纹」「模糊复原」两个 checkbox，默认关闭；开关状态跨文件保留，页面重载恢复默认。
- C05 勾选后显示「模糊类型：自动/运动/失焦」。
- 变更后 250ms debounce 自动重扫；处理中禁用全部增强控件。
- 日志：`计时 C04 频域分析：…ms`、`计时 C05 模糊复原：…ms（method，psf）`、跳过原因与诊断参数。
